## About the project

RealBeauty is a web application that tells what is inside a cosmetic or personal care product. The ingredients are given by barcode (looked up in Open Beauty Facts), typed by hand, or read from a photo of the label. An AI model returns a safety score from 0 to 100, a short summary, the ingredients that deserve attention and the beneficial ones. Results are saved locally, reused when the same ingredient list is given again, and listed on the page.

- **Source code:** [unibo-dtm-se-2425-RealBeauty/artifact](https://github.com/unibo-dtm-se-2425-RealBeauty/artifact)
- **Package:** [realbeauty on PyPI](https://pypi.org/project/realbeauty/)

RealBeauty is an educational project. Its results are generated by AI models and are not medical advice.

## How the site is built

The report is written in Markdown and published with GitHub Pages, using Jekyll and the [Just the Docs](https://github.com/just-the-docs/just-the-docs) theme (settings in `_config.yml`). Every push to the `main` branch rebuilds the site automatically.

To preview it locally (Ruby and Bundler required):

```bash
bundle install
bundle exec jekyll serve
```

The site is then available at <http://127.0.0.1:4000/report/>.

The structure of this repository comes from the course [report template](https://github.com/unibo-dtm-se/template-project-work).
